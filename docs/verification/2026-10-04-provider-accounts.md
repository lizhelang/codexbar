# 五类软件账号与额度管理验证

日期：2026-10-04，Australia/Melbourne。已安装本地版本：`2.0.0 (53)`。

## 已实现的界面与接入

管理页采用与参考图一致的平面软件分段，列出 Codex、Claude Code、OpenCode、Cursor 与 DeepSeek Harness。顶部保留日期、Token／费用汇总与来源状态。

- Codex 默认收起，点击标题展开或收起并保存状态；收起后仍显示账号／中转站数量和「连接中转站」。展开后保留 OAuth 多账号、逐账号额度、GPT Reserve、重置卡、路由与第三方中转站管理。
- 「排序」模式通过上下箭头调整五个软件的顺序；重新打开后恢复，管理页与看板额度页共用顺序。
- 其他软件直接显示额度、余额或连接状态，点击标题进入原生「账号与额度」窗口。自动识别、添加凭据、刷新和暂停在该窗口操作，目录与 CSV 等设置放入「读取设置」。

| 软件 | 原生账号能力 | 查询与数据边界 |
| --- | --- | --- |
| Cursor | 自动发现桌面登录；手动添加 Cookie／JWT；改名、暂停、更新或删除手动账号；选择看板账号 | 按稳定用户 ID 独立保存套餐、额度和历史；CSV 绑定所选账号；选择监测账号不会改变 Cursor 登录 |
| Claude Code | 自动发现本机 OAuth；手动保存网站 sessionKey，加载并明确选择组织；清除手动凭据后恢复自动发现 | 使用组织范围查询；多个组织时不擅自选择第一项；API Key 不冒充订阅账号 |
| OpenCode | 自动发现 Go 接入；命名连接支持 Go API Key／网站 Cookie；改名、排序、暂停、更新、移动凭据、删除 | 每个连接分别查询 Go 额度或网站余额；组合不同凭据须确认同一账号；保留明确绑定的 DeepSeek 自动连接 |
| DeepSeek Harness | 保留本地服务快照；发现明确绑定官方接口的环境 Key；手动保存／清除官方 DeepSeek API Key | 查询真实余额；自定义中转站凭据不会发送到官方接口 |

Claude Code、OpenCode、DSH 的本地历史继续按软件汇总，不把缺少可信身份的记录归到手动账号。Cursor 旧的匿名软件缓存不混入受管账号；单个账号查询失败仅保留其自身旧历史，并显示失败或需要登录状态。

## 凭据与异步保护

账号元数据／缓存与凭据分离，凭据文件权限为 `0600`、账号目录为 `0700`，不记录凭据值。保存失败回滚；拒绝危险符号链接；缓存用凭据指纹校验。暂停、删除、修改凭据与切换采集状态后，迟到请求不会重新写入旧数据。Cursor 稳定身份验证与 Claude 组织选择使用模拟服务回归验证。
