# 多工具用量、账号与界面修复验证

本轮覆盖多工具用量采集、账号接入、重置卡和额度页布局。公开记录只保留实现与验证结论，不附个人账号、真实用量或费用、本机日志和安装路径。

## 最终行为

- Antigravity 从本地 JSONL 和 SQLite 生成元数据读取实际 Token 计数，按事件去重，不从额度百分比或对话内容推算；无法读取的旧历史保持不完整状态。
- Cursor 软件用量汇总所有未暂停的稳定账号身份，额度跟随所选账号；失败时保留已读历史，不改变 Cursor 桌面登录。
- 工具展示名统一为 Grok，内部账号与缓存标识保持兼容。选中账号常驻，展开仅显示其他账号。
- Grok 接入统一账单导出，按账号读取 Grok Bot、Grok 网页与 Cursor 跨设备 Token；从近期向过去分段补历史。旧月份服务器错误保留近期与缓存记录，并明确标记不完整；当前窗口失败保留上一份快照。
- 新旧账本按产品、毫秒时间与 Token 分桶进行多重集去重，订阅内零扣费不误报为零模型成本。更新窗口整体替换，稳定账单 ID 用于重复检测。
- 菜单栏图标支持右键及 Control＋单击退出，移除 Codex「账号管理」标题旁的「…」菜单。
- 明确区分本期无记录、未知费用、已报告零费用及采集失败。OpenCode 的零费用结合提供商、模型目录和缓存单价验证，未知模型不一律归零。
- Claude 支持浏览器 OAuth、授权码回退及已有凭据接入；展示邮箱或名称，内部身份键仅用于账号绑定。
- Claude 重置卡保存结构化库存，过滤过期、暂停和未开始的卡；未知资格与零库存分开。使用入口打开官方用量页，不自动兑换。
- Codex 到期提醒可持久关闭并在设置中恢复，卡片本身及操作不受影响。
- 账号区统一平铺并去重。添加入口集中到顶部「＋」，账号数量和更新时间并入已有行，查看用量使用标题按钮，单个 Claude 重置卡合并成一行。
- 工具用量按当前时段 Token 降序，额度管理页保留用户手动顺序和折叠偏好。
- Antigravity OAuth 客户端配置由仓库外的用户私有文件或成对环境变量提供，不再内嵌；读取失败时不发起令牌请求，错误信息不携带配置内容。

## 验证范围

在隔离数据目录中运行了采集解析、跨账号聚合、免费模型定价、OAuth 回调、库存与缓存生命周期及原生 SwiftUI 窗口回归。以下为对应最终定向批次，测试有重叠，不将次数相加：

| 批次 | 结果 | 重点 |
| --- | --- | --- |
| 用量空时段、免费模型、Claude 身份 | 73 通过 | 原始零费用、读取异常、跨天与身份展示 |
| 工具排序与账号平铺 | 34 通过、1 跳过 | 当前周期排序、展开去重、路由控件与菜单 |
| 重置卡与提醒关闭 | 72 通过、2 跳过 | 库存过滤、旧缓存、失败保留、持久关闭与官方链接 |
| 信息密度与入口合并 | 26 通过、1 跳过 | 窄窗口、实际排序交互、用量跳转及额度保留 |
| OAuth 客户端配置外部化 | 16 通过 | 私有文件权限、环境变量配对、固定错误、登录/刷新请求参数 |
| Grok 展示、账单解析与账号回归 | 59 通过 | CSV 计数、账号隔离、当前账号布局及原生展开 |
| Grok 最终数据回归 | 31 通过 | 逆序分窗、毫秒边界、跨产品去重、空窗口替换与真实账号服务端同步 |

跳过项为离屏进程未公开辅助功能树的专项检查，或默认关闭的真实凭据探针；相关视觉场景仍通过原生截图及隔离数据验证。截图识别误差只对已核对像素的测试夹具进行有限适配，账号数量、顺序、位置和状态断言保留。官方使用链接由 `OpenURLAction` 拦截验证，没有真实兑换重置卡。

同一 360 pt 夹具中，信息合并使 Antigravity 标题上移约 68 pt，未缩小账号与额度字号。界面与用量修复已完成 Release 构建、签名和本地应用验证；随后配置外部化通过隔离构建与定向回归，私有配置读取验证不发起网络请求。此记录不代表已发布新的 GitHub Release。

Grok 真实账号验证通过显式开启的只读探针完成：确认服务端返回 Grok Bot 与 Grok Chat 的当日记录；旧月份返回服务器错误时近期计数仍保留，并标记历史不完整。探针只输出汇总和接口状态，不输出凭据、账号标识或响应正文。公开记录不附真实计数及个人账号资料。
