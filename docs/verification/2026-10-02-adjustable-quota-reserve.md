# 聚合模式预留比例可调

## 已实现

- 设置 → 账户设置 → 聚合模式：在预留开关下增加“预留比例”，可输入整数或用加减按钮调整，范围 1%–100%，默认 5%。修改账户设置后需保存。
- 比例独立于启用开关保存；切换模式、重新打开设置和重启不会丢失。旧配置缺少比例字段时使用 5%。
- 仅对当前账号明确的 5 小时普通额度生效。设为 20% 时，已用达到 80% 后不再分配新的聚合请求；其他账号不可用时不动用预留部分。
- HTTP、sticky 绑定和已连接 WebSocket 的新 `response.create` 使用相同阈值；已经执行的请求及控制消息不被中断。说明和错误文字显示实际比例。
- 同步修正账号选中 GPT Reserve 时的推理强度保存，按该账号模型能力校验；普通默认模型保持原有校验。
