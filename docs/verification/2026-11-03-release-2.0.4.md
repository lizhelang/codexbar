# v2.0.4 发布验证

日期：2026-11-03（Australia/Sydney）。版本：2.0.4（build 78）。

## 范围

- 基于 v2.0.3 的 `71057b2933b6dfebfb7f92badf302b4c971fbd61`，加入额度恢复后自动继续原线程的服务、账号与线程确认界面、生命周期接入和回归测试。
- 新安装默认关闭；用户需要确认监测账号和线程。聚合网关、远程线程、子代理及无法确认的独立额度不自动恢复。
- 保留原线程队列桥接、发送前持久化、防重复、停止／新输入／归档／Goal 暂停保护。入队回执与原线程实际运行分别记录。

## 定向回归与审查

本轮分批运行并按测试名称去重，覆盖 **190 项不同用例，最终 190 通过、0 失败、0 跳过**。这是受影响路径的定向回归，不是整个仓库测试集的声明。

- 自动继续：账号解析 7、协调器 20、线程观察 32、额度判断 11、界面 2、队列桥接 14，共 86 项。
- 接入回归：生命周期 4、菜单通知 3、菜单展示 19、设置 43、更新检查 15、额度服务 20，共 104 项。
- 独立审查发现并修复同一工作区不同登录用户可能被误认成同一账号的问题。新回归先证明旧逻辑会放行错误身份，再验证工作区与稳定用户身份必须同时匹配；身份缺失或冲突时拒绝续跑。
- 独立审查发现并修复 legacy 日志缺少本轮进展标记，导致第二个额度周期跨重启后可能一直等待的问题。新回归使用真实日志观察器与隔离队列替身，先复现第二次恢复未发送，再验证完成工作后的第二次恢复及重启防重复。
- legacy 只认定当前活动轮次的非空助手消息和明确完成的工作。异轮、无效身份、终态后的事件、推理、空文本和未完成工作不计入进展。保留 paginated 与原始 rollout 各自的事件格式。
- 两项审查问题的限定复查均通过，未发现其他可证实的阻断问题。
- 已查看原生 SwiftUI 离屏渲染：默认账号选项、关闭状态、等待记录、无法确认发送结果的提示及取消入口可见。
- 当前桌面应用自带 CLI 的 `queue --help` 可用，参数与桥接使用的 `--thread`、`--message` 一致；本项检查没有发送消息。

## 验证边界

测试使用隔离的配置目录、合成账号与线程状态，以及队列替身；真实进程测试只执行本地测试脚本。需要专用桌面线程的显式选择验收用例未在本轮运行。

本轮没有消耗真实账号额度来制造耗尽／恢复，也未在真实 Codex 界面执行「停止」按钮的端到端验收。状态回放、命令帮助和入队替身不能替代这些验证。应用始终区分「已入队」和「已确认运行」，结果不明确时不会自动重复发送。

安装与启动在发布完成后单独核验；发布前的测试和构建不代表已安装应用或服务商端到端验收。
