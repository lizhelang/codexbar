# v2.0.2：更简洁的账号界面与跨设备 Grok 用量

v2.0.2 精简了额度页和账号管理，把常用信息放在同一行，补上容易找到的退出入口，并完善 Grok、Antigravity、Claude 等工具的账号、Token 和费用统计。以下为相对上一正式版本 **v2.0.1** 的变化。

## 退出更容易，界面更统一

- **右键单击菜单栏 Codexbar 图标 →「退出 Codexbar」**，也支持 Control＋单击。
- 仍可先点开 Codexbar 面板，让应用获得键盘焦点，再按 **⌘Q** 退出。这是应用内快捷键，不是全局退出快捷键。
- 移除 Codex「账号管理」标题旁的「…」菜单，退出操作移到菜单栏右键菜单，语言设置统一放在「设置 → 常规」。
- 添加账号和连接服务集中到顶部「＋」，不再在每个软件下面重复占用一行；各软件标题旁的小图表按钮可直接查看用量。
- Codex、Claude、Antigravity、Grok 等账号内容统一平铺。**当前账号始终显示在上方，展开后只列出其他账号**，不再重复显示同一个账号和额度。
- 收起状态统一使用额度名称、重置倒计时、进度条和百分比；Codex 的模型、推理强度、服务档位和上下文选择仍保留。
- 账号数量并入软件标题，当前账号状态和更新时间并入身份行，减少重复的「剩余」「更新」「查看用量」等独立行；单张 Claude 重置卡也压缩为一行。
- 工具页默认按所选时段的 **Token 用量从高到低** 排序；额度管理页仍保留自定义软件顺序与折叠偏好。
- 修复添加账号等弹窗操作被外部点击监听误关的问题。

这些调整回应了 [#60：退出入口与界面拥挤反馈](https://github.com/lizhelang/codexbar/issues/60)。

## Grok：统计同一账号在其他设备上的用量

- 原 Cursor 工具在界面中更名为 **Grok**，已有账号、选择状态和历史继续沿用；保留旧版 Cursor CSV 导入，并明确标注其格式范围。
- 接入统一账单明细，统计 **Grok Bot、Grok 网页（Grok Chat）和 Cursor** 的实际 Token，包括同一账号在其他电脑上的使用。
- 修复旧 Cursor 用量接口只返回旧记录、遗漏新版 Grok Bot 和网页消耗的问题；工具页显示 Token，不再用账户额度替代用量。
- 汇总所有未暂停账号的已知用量，额度展示仍跟随当前选中的监测账号。切换监测账号不会改动 Cursor 桌面端登录。
- 兼容新版统一订阅的套餐、包含用量和重置周期，同时保留旧套餐的额度窗口。
- 从近期向过去补齐服务端可查询历史；后续刷新更新近期记录并保留较早历史。旧月份接口失败时标明不完整，**不会让今天已经读到的用量消失**；当前窗口查询失败时保留上一份快照。
- 新旧账本按产品、时间和 Token 分桶去重，避免相同请求重复累计；修复旧接口分页期间新增记录导致的页码漂移和同步超时。

## Antigravity：新增账号管理、额度和 Token 统计

- 新增独立 Antigravity 软件分段，可识别本机登录、保存多个账号、切换账号、刷新额度、重新授权和删除账号。
- 提供浏览器 Google OAuth 授权、回调链接回填和已有令牌导入入口。
- 显示 Gemini、Claude/GPT、Argon 等上游实际返回的额度窗口、重置时间、套餐和更新状态；展开后仅显示其他账号。
- 从本地日志和数据库的生成元数据读取实际输入、输出与缓存 Token，并按生成事件去重；用量可进入工具、模型和会话统计。
- 额度与用量分别读取：**不会根据剩余额度百分比猜测 Token**。无法读取的旧记录会标明不完整，不伪造为零用量。
- Google OAuth 客户端配置改为用户私有配置或成对环境变量提供，**不随源码或安装包分发**。浏览器授权和令牌刷新前，需要按 [README 的 Antigravity 配置说明](https://github.com/lizhelang/codexbar/blob/v2.0.2/README.md)提供自己的客户端配置。

## Claude：登录、账号名称和重置卡

- 新增浏览器 OAuth 登录，支持自动回调与手动授权码回填；保留已有 Claude Code 登录和网站凭据接入方式。
- 完善本应用保存的 OAuth 登录刷新；自动识别的 Claude Code 凭据保持只读。账号身份、组织选择与历史缓存分别校验，避免账号混用。
- 修复账号名称显示内部身份 ID 的问题，优先显示可读的邮箱或名称。
- 重置卡改为明确的库存展示，包含可用张数、适用范围和到期时间；过滤过期、暂停或尚未生效的卡，区分「没有库存」与「资格或数据未知」。
- 点击重置卡「使用」会打开 Claude 官方用量页，由用户确认账号后操作，不自动兑换。
- 补齐一小时缓存写入计数与对应费用计算，改善混合缓存记录的估算准确性。

## Codex：可关闭提醒与路由修复

- 重置卡即将到期的提醒可点击「×」关闭，重启后仍记住；可在「设置 → 面板 → 额度提醒」重新开启。关闭提醒不隐藏或消耗重置卡。
- 当前账号与其他账号的额度行统一布局，减少展开后的重复内容，保留账号切换、聚合模式和路由选择。
- 修复 OpenAI OAuth 经本地网关路由时，手动关闭 WebSocket 未正确生效的问题；普通路由和 Reserve 别名均遵循该设置，见 [#59](https://github.com/lizhelang/codexbar/pull/59)。

## 费用与用量显示更准确

- 明确区分「本期暂无记录」「用量暂不可用」「费用未知」和真实零费用；历史不完整但有已读记录时，继续显示已知 Token。
- OpenCode 结合提供商、模型目录和明确的免费模型标识判断零费用，已确认的免费使用显示 **$0.00**；未知模型或缺失单价不再一律当作免费。
- 补齐当前 Claude、Gemini 等模型的单价与已确认别名，改善多模型会话的已知费用汇总。缺失费用的记录仍计入 Token，费用只显示可核实的部分。
- 订阅内「额外扣费为零」与模型用量价值分开保存，不把未额外收费误解为零模型成本。
- 工具页进度条仍用于相对比较：所选时段中 Token 用量最高的工具作为满条参照，**满条不表示账户额度耗尽**。

## DeepSeek Harness 与其他修复

- DeepSeek 官方余额连接可实时查询，避免把 DSH 保存的余额快照当作新查询结果；刷新失败时保留上次金额与时间，并说明失败。
- 自动发现官方连接时检查实际接入地址；手动确认官方账号后，可复用对应 DSH 凭据连接官方余额接口。
- 修复 DSH 同版本日志中优先读取较旧压缩副本的问题，改为采用较新的记录；补齐模型、提供商与上下文输入 Token 的读取。
- 完善 OpenCode Go、网站余额及自定义接入的额度状态提示，不把未提供额度接口的服务显示为正常零额度。
- 增加复杂度与覆盖率报告工具，补充账号隔离、用量解析、费用、重置卡及原生界面回归，并补齐所参考开源项目的许可声明。

## 数据、安装与验证范围

- 版本为 **2.0.2（build 75）**，面向 Apple Silicon 与 Intel Mac。
- Grok 的账号用量来自服务端；Codex、Claude Code、OpenCode、DeepSeek Harness 和 Antigravity 的本地历史仍受本机可读取记录范围限制，不能据此补出其他设备的全部历史。
- 服务端旧月份、过期登录或无法解析的旧格式可能导致历史不完整。费用估算也不等同于官方账单；没有可信单价或计费信息时仍显示未知。
- 已完成账号隔离、CSV 计数、分窗同步、去重、空窗口替换、失败保留及原生布局等定向回归，并通过显式开启的真实账号只读检查，确认能够取得 Grok Bot 与 Grok Chat 的当日记录。各批次有重叠，不将测试次数相加；详见[验证范围](https://github.com/lizhelang/codexbar/blob/v2.0.2/docs/verification/2026-10-21-provider-usage-ui.md)。
- 安装包使用 **ad-hoc 签名**，未使用 Developer ID 签名，也未经过 Apple 公证。首次打开可能需要在 macOS「系统设置 → 隐私与安全性」中手动允许。
- 应用内更新功能提供版本检查和安装包下载引导，仍需用户完成安装；不会自动替换应用并重启。
