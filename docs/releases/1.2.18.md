# v1.2.18：第三方独立配置与 WebSocket 手动关闭

此次正式版包含 v1.2.16 之后的第三方服务配置改进，以及 Issue #55 的 WebSocket 关闭选项。应用提供 Apple Silicon / Intel 通用架构安装包。

## 本次改进

- 第三方服务改用 Codex 独立的 `model_providers` 配置，切换时保留 OpenAI OAuth 登录态。新建的内置预设使用 Responses API；Custom 仍可选择 Chat Completions 兼容网关。
- 设置中的「关闭 WebSocket」让 OpenAI OAuth 直连和第三方 Responses 服务使用 HTTP Streaming。OpenAI 直连会切换到保留 OAuth 登录态的命名 provider；选回「跟随 Codex 默认」即可恢复内置连接方式。
- 取消按 HTTP/SOCKS 代理隧道猜测 WebSocket 能力的自动探测。隧道建立不代表 WebSocket 握手成功，自动模式现在遵循 Codex 默认策略。
- 设置保存会立即同步传输选项，并清理旧版生成在 `config.toml` 根层、Codex 实际不会读取的 `supports_websockets` 键。

## 适用范围

「关闭 WebSocket」覆盖 OpenAI OAuth 直连和第三方服务。本地 OpenAI 账号池的聚合网关维持原连接方式，设置页已说明这一点。切换传输方式后，请新开 Codex 会话。

第三方服务及 Chat Completions 兼容网关的能力仍受上游协议与模型限制。DeepSeek Responses 当前并不支持 Codex 的所有自定义工具；Chat Completions 本地转换网关暂不支持多代理工具分组和联网搜索。此前未正式发布的第三方配置变更及迁移说明详见 [v1.2.17 草稿](1.2.17.md)。

- Release 通用架构构建、签名、本机覆盖安装和启动已通过。
