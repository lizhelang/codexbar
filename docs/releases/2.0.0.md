# v2.0.0：用量看板与多工具统计大版本

这是从上一个打包安装版本以来的一次完整升级。v2.0.0 把 codexbar 从“账号和 provider 切换工具”扩展成了 macOS 菜单栏里的 AI 用量看板，同时保留原有的 OpenAI 登录、账号切换和 provider 管理能力。

## 主要变化

### 全新的用量看板

- 顶部标题固定为 `codexbar`，不再因为 Token / Cost 视角切换而变化。
- 新增今天、本周、本月、总计等时间范围，以及近 7 天、近 30 天和全部工具视角。
- Token 和费用切换入口集中到右上角，减少对标题区域的干扰。
- 用量趋势支持折线图与柱状图切换；柱状图采用居中的紧凑排列，避免少量数据被拉到两端。
- 增加项目、会话、设备和工具维度的用量展示，支持分页与展开查看。
- 成本卡片、活动天数、连续活跃、最长连续和单日峰值等摘要指标统一到看板中。
- 看板布局参考 Token Monitor 的信息层级：先显示当前总量和时间范围，再显示趋势与摘要，最后进入明细。

### 多工具用量汇总

- Codex：读取本机 `~/.codex/sessions` 和 `~/.codex/archived_sessions`。
- Claude Code：后台只读扫描本地会话记录。
- OpenCode：读取本地数据库或旧版记录。
- DeepSeek Harness：读取本地 DSH 会话记录。
- Cursor：同步已登录桌面端的用量，并支持 Usage 页面 CSV 导入。
- OpenCode 额度只读取 OpenCode 自己的 OpenCode Go / 接入服务；OpenCode 内保存的 OpenAI OAuth 账号不会被用于 OpenCode 额度统计。
- 支持按工具筛选，或在“全部工具”中查看跨工具汇总。

### 更稳的本地索引与缓存

- Codex 历史用量写入 `~/.codexbar/cost-usage.sqlite` 派生索引。
- 只追踪 JSONL 新增或变化的字节，后台分片追赶大型历史目录。
- 扫描时保留上一次可用结果，并展示扫描状态，不把“尚未完成”伪装成真实的零用量。
- 跨工具按日汇总写入 `~/.codexbar/tool-usage-summary.json`，不保存对话正文或登录凭据。
- 增加快照、增量扫描、聚合和项目归属测试，覆盖大型历史记录场景。

### OpenAI 账号与额度能力

- 保留多 OpenAI OAuth 账号管理、手动切换和聚合网关两种模式。
- 增加当前账号的 Reserve 模型选择与可选额度预留策略。
- 增加重置卡、额度窗口和手动额度对齐入口。
- 改善 OAuth 刷新、并发更新、账号切换和状态保留，避免新资料覆盖用户刚保存的状态。
- 账号列表支持按当前用量或手动顺序展示。
- 支持导入 / 导出 OpenAI 账号数据，与 Sub2API 格式互通。

### Provider 与协议兼容

- DeepSeek、智谱 GLM、OpenRouter、Requesty 的内置预设统一按 Responses API 配置。
- Custom provider 可选择 Responses 或 Chat Completions。
- Chat Completions 增加本地转换网关，支持基础 function / custom 工具调用与结果回传。
- 保存旧 Chat 配置时增加兼容性检查和迁移预览，不静默改写已有服务、账号或密钥。
- 保留用户手工维护的 provider、profile、MCP 和模型目录配置。
- 对 DeepSeek 工具限制、Chat 网关不支持的工具类型和 Responses 差异给出明确提示。

### 设置、更新与运行时

- 设置页拆分为更清晰的账号、provider、用量、设备同步、订阅和更新区域。
- 增加设备用量同步、订阅记录、登录项和应用偏好相关能力。
- GitHub Releases 更新检查过滤草稿、预发布版本和缺少安装包的版本。
- 保持 guided download / install 边界，不在没有确认的情况下替换用户正在运行的应用。
- 保持单实例、菜单栏状态项和 Codex 本地回调登录流程。

## Token Monitor 视觉参考

本版本参考 Token Monitor 的“总量优先、时间范围明确、趋势和摘要分层”的阅读方式，重新整理了看板的控件位置和图表表达。参考的是信息组织和交互层级，不复制其品牌、资源或实现；codexbar 仍保留自己的菜单栏工作流、OpenAI 账号管理和本地数据边界。

## 数据与费用口径

- Codex Token 统计口径为 `input + cached_input + output`。
- 费用是本地模型价格表或来源记录的估算，不等同于官方账单。
- 数据覆盖范围取决于本机历史文件、Cursor 接口或导入 CSV 的完整性。
- 未配置价格的模型费用按 0 处理，但 Token 仍正常统计。

## 验证与已知边界

- 已完成 Debug / Release 构建、单元测试和安装包启动验证。
- 已验证通用构建包含 `arm64` 与 `x86_64` 架构。
- 本地历史扫描、第三方来源同步和真实账号数据仍受各来源文件、接口和权限影响。
- 用量看板属于本地记录视角，不承诺与服务商实时账单完全一致。
