# GPT Reserve 模型选择

管理页沿用现有模型下拉框。当前请求目标是 OAuth 账号，且该账号的 Reserve 额度可用时，菜单显示「GPT Reserve」（实际模型 ID `gpt-reserve`）。其他账号有额度不会让当前账号获得此选项。账号过期、停用、额度未知或耗尽时不提供新选择；已选模型不会自动切换或转用普通额度。

用户选择后保存到该账号的 `selectedModelID`，同步为后续新 Codex 对话的默认模型。切换账号按各自模型选择恢复。普通全局默认模型保持原值；切回普通模型仍更新普通默认。

Reserve 新对话直接使用目标账号的官方 OAuth 连接，不需要强制代理。原有聚合网关与旧对话所存的服务商地址继续按普通模式工作；网关不改写 Responses、Compact 或 WebSocket 的模型参数。现有对话中的模型及显式模型参数由 Codex 自己管理，不会被模型菜单强制覆盖。

推理强度、服务档位与上下文优先使用 Codex 模型目录和用户覆盖。缺少目录时 Reserve 支持 low、medium、high、xhigh、max；不兼容的强度回落 medium，上下文默认 272000。

旧 `openAI.forcedReserveAccountID` 配置被忽略，后续保存会移除；不会据此自动选择 Reserve。强制开关、账号锁定、模型改写和 WebSocket 强制重连已删除。

本地回归使用隔离账号与模拟请求，不消耗真实额度。真实账号的模型权限和额度记账需由服务端响应确认。
