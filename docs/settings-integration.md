# 看板与设置整合（本地构建 35）

## 菜单布局

- 保留顶部应用图标、速率、日期范围和设置入口。
- 看板中将统计标题、看板／管理、刷新、图表展开合为一行。
- 管理中将 Codex 管理、看板／管理、刷新、添加、更多合为一行。
- 设置窗口打开时不自动选中首个按钮，键盘 Tab 导航仍可用。

## 设置分组

| 分组 | 页面 | 实际功能 |
| --- | --- | --- |
| 账户设置 | 账户与路由 | 保留切换、聚合、指定模型、远端账户、代理及原账户行为 |
| 应用设置 | 常规 | 语言、系统登录启动、Codexbar 更新检查和后台下载、诊断 |
| 应用设置 | 主画面 | 默认日期／指标、页面及主页模块显示顺序、列表数量、显示币种及手动汇率 |
| 应用设置 | 窗口 | 固定高度、底部拖动、点击外部是否保持打开 |
| 应用设置 | 外观 | 主题、强调色、透明度、字号、应用及工具图标、速率和菜单栏百分比 |
| 应用设置 | AI 工具 | 五个工具启用及排序、采集频率、自定义目录、模型显示别名、Codex 记录定价、用量导出 |
| 应用设置 | 额度 | 刷新频率、菜单邮箱隐藏、剩余／已用显示和排序权重 |
| 应用设置 | 订阅记录 | 本地套餐及充值记录、金额、币种、周期、续订日期 |
| 应用设置 | 多设备同步 | 本地模式、共享目录、iCloud Drive 目录、Hub 客户端及主机 |

原“记录”分类由看板的模型、项目及会话页面承接；独立“更新”分类合并到常规。

## 数据与行为

- 账户、额度和 Codex 模型价格沿用原来的保存流程；应用显示偏好即时生效；同步配置通过该页的“应用同步设置”生效。
- 自动下载使用本项目发布源，下载后由用户发起安装。不会自动替换正在运行的应用。
- 自定义目录只改变外部工具记录来源，不修改 Codex 的认证文件或配置文件。
- 显示别名不合并原始模型分组；手动汇率只改变显示，不改变 USD 原始账目。
- 多设备仅交换按日、按工具的 Token 和费用汇总，不交换账户、凭据、会话标题或正文。
- Cursor 的服务端／CSV 是账号级统计，设备页不累加它，避免多台设备重复计数；工具页仍可查看。
- Hub 默认仅本机监听，局域网监听需在设置中开启并提供配对密钥。协议用于 Codexbar 设备之间。
- iCloud Drive 使用用户选择的共享目录。没有替用户启用云同步或登录启动。

参考项目的悬浮球、贴边浮窗、WSL 和专属统计引擎维护项，不作为菜单栏版的空开关加入。

## 验证范围

- 应用偏好、更新、同步、订阅、设置状态、窗口尺寸及看板数据的 81 项回归通过。
- 同步验证使用临时目录与本机回环的模拟设备，未代替真实第二台设备及 iCloud 的端到端验收。
- 2 项原生视图离屏测试通过，并实际查看了看板、管理和默认设置窗口的渲染图；不截取用户桌面。
